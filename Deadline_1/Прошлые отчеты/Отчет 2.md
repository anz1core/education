#### Задание 1.

Напишите блок схему отправки ping с устройства на устройство.

**Условия**: В блок схеме должно быть: 
- блоки ввода данных для ip
- как минимум один цикл
- блок вывода данных

```mermaid

flowchart TD

A(Начало)

B[/Введите айпи удаленного клиента/]

D[/Сколько запросов отправить?/]

C[Отправление пакетов на этот айпи адрес]

N{Был получен эхо-ответ?}

F{Отправлены все запросы?}

G[/Удаленный клиент не доступен/]

H[/Ответ от: IP удаленного клиента Задержка в мс:  число байт:  TTL:/]

I(Конец)

A --> B

B-->D

D-->C

C-->F

F-->N

F-->|Нет|C

N-->|Нет|G

G-->I

N-->|Да|H

H-->I
```

#### Задание 2.

Вспомните как работает протокол ospf, а в частности его алгоритм поиска кратчайшего пути. Составьте блок-схему отправки сообщения с одного устройства до другого, которые объединены несколькими маршрутизаторами с ospf протоколом.

**Условия**: В блок схеме должно быть: 
- должно быть как минимум одно условие
- должен быть как минимум один цикл
- должна быть как минимум одна определённая переменная

```mermaid

flowchart TD

S([Начало]) --> D[/Введите IP получателя/]

D --> I[Текущий роутер: Таблица маршрутов = ]

I --> L{Есть ли маршрут до цели?}

  

L -->|Да| F[/Отправить пакет на следующий роутер/]

L -->|Нет| E[/Вывести: "Маршрут не найден"/]

  

F --> N[Роутер = следующий узел]

N --> C{Достигнут получатель?}

  

C -->|Да| P[/Вывести:"Доставлено"/]

Q([Конец])

C -->|Нет| L

E --> Q

P --> Q
```

#### Задание 3.

Вспомним как работает протокол ssh. Составим блок-схему подключения одного узла к другому через ssh

**Условия**: 
- Должно быть условие проверки пароля
- У пользователя есть 3 попытки ввода пароля
- Должны быть блоки ввода и вывода информации

```mermaid

flowchart TD

  

A([Начало]) --> B[/Введите IP-адрес и имя пользователя/]

B --> I[Попытки = 0 Максимум 5]

  

I --> L{Попыток меньше 5?}

L -->|Да| V[/Введите пароль/]

V --> C{Пароль верный?}

  

C -->|Да| S[/Подключение установлено/]

S --> Q([Конец])

  

C -->|Нет| J[Попытки + 1 ]

J --> N[/Неверный пароль/]

N-->L

  

L -->|Нет| F[/Доступ запрещён. Превышено число попыток/]

F --> Q
```
